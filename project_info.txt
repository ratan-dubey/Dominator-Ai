How to Run Project Locally
-------------------------
1. Prerequisites:
   - Python 3.x
   - pip (Python package manager)
   - Git (optional)

2. Setup:
   ```bash
   # Clone repository (if using Git)
   git clone <repository-url>
   cd dominator-ai

   # Create virtual environment
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate

   # Install dependencies
   pip install -r requirements.txt
   ```

3. Run Application:
   ```bash
   python app.py
   ```

4. Access:
   Open browser and navigate to:
   http://localhost:5000

Backend Connection
----------------
The frontend communicates with the backend through:

1. RESTful Routes:
   - /login (POST) - User authentication
   - /signup (POST) - User registration
   - /chat (GET) - Chat interface
   - /account (GET/POST) - Profile management
   - /uploads/<filename> (GET) - File serving

2. Data Storage:
   - User data in SQLite database
   - Chat history in localStorage
   - Profile pictures in static/uploads

3. Session Management:
   - Flask session for authentication
   - Cookies for persistent login

Deployment Instructions
---------------------
1. Prepare for Deployment:
   - Update SECRET_KEY in app.py
   - Set FLASK_ENV to production
   - Configure database path
   - Set up proper file permissions

2. Deployment Options:
   a. Traditional Hosting:
      - Upload files to server
      - Set up virtual environment
      - Configure web server (Nginx/Apache)
      - Set up WSGI (gunicorn)

   b. Platform as a Service:
      - Heroku:
        ```bash
        heroku create
        git push heroku main
        heroku config:set FLASK_ENV=production
        ```

      - Render.com:
        - Connect GitHub repository
        - Set build command: pip install -r requirements.txt
        - Set start command: gunicorn app:app
        - Add environment variables

3. Domain Setup:
   - Purchase domain
   - Configure DNS settings
   - Set up SSL certificate
   - Update CORS settings if needed
