Changes Made to Replace OpenAI with Groq and Hugging Face APIs

1. Modified Files:
   - app.py

2. Changes in app.py:
   a) Removed:
      - OpenAI import and client initialization
      - OpenAI API key
      - get_openai_response function
      
   b) Added:
      - Groq and Hugging Face imports
      - API client initializations for both services
      - Constants for models and retry settings
      - get_groq_response function for text-only queries
      - get_huggingface_response function for image+text queries
      - get_ai_response function to route requests
      
   c) Modified:
      - /ask route to handle both text and image inputs
      - Error handling and retry logic
      - Response format standardization

3. Environment Variables Required:
   - GROQ_API_KEY
   - HF_API_KEY

4. Test Cases:

   a) Text-only Query (Groq API):
   ```python
   # Sample request
   {
       "message": "What is artificial intelligence?",
       "chat_id": "optional_chat_id"
   }
   ```

   b) Image+Text Query (Hugging Face API):
   ```python
   # Sample request
   {
       "message": "What's in this image?",
       "image": "base64_encoded_image_data",
       "chat_id": "optional_chat_id"
   }
   ```

5. API Models Used:
   - Groq: mixtral-8x7b-32768
   - Hugging Face: microsoft/kosmos-2-patch14-224

6. Error Handling:
   - Rate limiting with exponential backoff
   - Authentication errors
   - Invalid responses
   - Image processing errors
   - Network timeouts

7. No Changes Made To:
   - Database models
   - Frontend code
   - Authentication system
   - Chat history functionality
   - User interface
   - File upload system
